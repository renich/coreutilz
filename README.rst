==========
Coreutilz
==========

A modern, idiomatic Zig implementation of GNU Coreutils.

Overview
========

Coreutilz aims to provide a fast, safe, and compliant set of core system
utilities, following the spirit of the original GNU project while leveraging the
power of the Zig programming language.

Documentation
=============

* `Style Guide <docs/technical/style.rst>`_: Our coding standards and
  conventions.

Development
===========

To build the project, ensure you have Zig installed and run:

.. code-block:: bash

    zig build

To run the tests:

.. code-block:: bash

    zig build test
